# 星夜宇宙 · Stroke Cosmos

把梵高《星空》从「一幅画」解构成一个**可以飞进去的巨大 3D 宇宙**。
TypeScript + Three.js，模块化工程，电影级运镜，24 秒一镜到底。

## 创意概念

《星空》的力量来自**有方向的笔触**。这个项目把每一道笔触变成一个发光粒子，
再把它们编织成散落在虚空中的**巨大三维漩涡**：

| 元素 | 原画对应 | 三维化处理 |
| --- | --- | --- |
| `Nebula` | 天穹底色 | 半径 26000 的程序化 fbm 星云穹顶（无接缝，3D 噪声） |
| `Starfield` | 点点繁星 | 16000 颗视差星点 + 银河带 |
| `StrokeField` | 旋涡笔触 | 6 个巨大漩涡，每道笔触沿 curl-noise 流场呼吸、整体自转 |
| `VortexGalaxy` | 主漩涡 | 4 旋臂对数螺旋星系，差速旋转 + 炽热核心 |
| `ColossalMoon` | 月亮 | 半径 700 的巨月，表面 fbm 笔触，近距离掠过 |
| `CypressGate` | 丝柏树 | 成对暗色尖塔，构成一道「星门」 |

## 运镜（6 镜 / 24s）

十帧相机关键帧（等距 t = i/9）驱动两条 Catmull-Rom 曲线（位置 + 注视点），
每帧还带独立的 **FOV 推拉** 与 **roll 翻滚**：

1. **远观 · 星夜全景**（0–19%）缓推建立全貌
2. **冲入 · 穿越丝柏星门**（19–30%）从一线缝隙穿过
3. **掠过 · 巨月**（30–50%）近距压迫
4. **坠入 · 螺旋星系核心**（50–67%）FOV 88° 冲击
5. **俯瞰 · 巨大空间**（67–86%）拉升回望构造
6. **漂移 · 星海收束**（86–100%）缓缓远离

## 后处理

`PostFX`：UnrealBloom（发光）＋ 暖冷分离调色 ＋ 径向色差 ＋ 暗角 ＋ 动态胶片颗粒。

## 运行

```bash
npm install
npm run dev        # 打开 http://localhost:5173
npm run build      # 产出 dist/（静态、可直接托管）
npm run preview
```

## 确定性渲染（导出视频用）

访问 `?render=1` 会冻结自动播放，并暴露：

```js
window.__setT(T)   // T ∈ [0,1]，精确渲染任意时刻
```

`T` 是世界时间的唯一函数 —— 相同 T 永远渲染完全相同的画面，
因此可以用无头浏览器逐帧截图，再用 ffmpeg 编码成视频。
